This is basically an experiment.

I have around 25+ years of software dev experience, and with the ever closer AI revolution coming, I decided to use BitBurner as a vehicle to experiment with AI prompting for code generation.

Why BitBurner makes sense for this?
It uses vanilla JS, along with a well defined API, all of which can be well prompted and confined within a limited system.

Did I write any of the code?
Yes, I wrote original, bare-bone versions of what I considered the original sub-set of core scripts were, but then passed them into GPT, and let her rip.
Over time, I was able to refine scripts, split them, and create diagnostic tools that gave actionable, (AI), feedback.  It's still a work in progress, but I invite people to read the code, 
critique, and improve the script library.

Again, this is not an example of my coding skill, nor a perfect suite of scripts.  It is, instead, an experiment.
